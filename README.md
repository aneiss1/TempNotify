# TempNotify

A lightweight, ad-free Android app that displays the current local temperature (`°F`) persistently in the top status bar (next to the clock) and shows the **Feels Like** temperature, daily High/Low, and sky condition in the notification shade.

## Features
- **Top Status Bar Temperature Icon**: Dynamically renders the current temperature (e.g., `72°`) in the top status bar.
- **Persistent Notification Shade**:
  - Current temperature, sky condition, and automatic city name
  - **Feels Like** temperature + daily High/Low
  - Quick **Refresh** button
  - Tapping the notification opens the **Pixel Weather** app (`com.google.android.apps.weather`) if installed.
- **Zero Ads / Zero API Keys**: Powered by [Open-Meteo](https://open-meteo.com/).
